NoVPN v2.2 — настройка PAC

Требуется собственный или доверенный HTTP CONNECT-прокси. Эта страница не предоставляет сервер. Не вводите логины или пароли.

Разместите PAC на доверенном HTTPS-хостинге, затем укажите его URL в Windows → Сеть и Интернет → Прокси → Использовать сценарий настройки. Проверьте обычный браузер, затем OBS. OBS может не учитывать системный PAC.

Откат: отключите сценарий настройки. Не используйте неизвестные публичные прокси.
